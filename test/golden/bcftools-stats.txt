Name:  bcftools-stats-input


Desc:  bcftools-stats-input


Usage:
bcftools stats [options] <A.vcf.gz> [<B.vcf.gz>]


(bcftools-stats-input) --af-bins  ::  LIST
Allele frequency bins, a list (0.1,0.5,1) or a file (0.1\n0.5\n1)

(bcftools-stats-input) --af-tag  ::  STRING
Allele frequency tag to use, by default estimated from AN,AC or GT

(bcftools-stats-input) -1 --1st-allele-only  ::  
Include only 1st allele at multiallelic sites

(bcftools-stats-input) -c --collapse  ::  STRING
Treat as identical records with <snps|indels|both|all|some|none>, see man page for details [none]

(bcftools-stats-input) -d --depth  ::  INT,INT,INT
Depth distribution: min,max,bin size [0,500,1]

(bcftools-stats-input) -e --exclude  ::  EXPR
Exclude sites for which the expression is true (see man page for details)

(bcftools-stats-input) -E --exons  ::  FILE.gz
Tab-delimited file with exons for indel frameshifts (chr,beg,end; 1-based, inclusive, bgzip compressed)

(bcftools-stats-input) -f --apply-filters  ::  LIST
Require at least one of the listed FILTER strings (e.g. "PASS,.")

(bcftools-stats-input) -F --fasta-ref  ::  FILE
Faidx indexed reference sequence file to determine INDEL context

(bcftools-stats-input) -i --include  ::  EXPR
Select sites for which the expression is true (see man page for details)

(bcftools-stats-input) -I --split-by-ID  ::  
Collect stats for sites with ID separately (known vs novel)

(bcftools-stats-input) -r --regions  ::  REGION
Restrict to comma-separated list of regions

(bcftools-stats-input) -R --regions-file  ::  FILE
Restrict to regions listed in a file

(bcftools-stats-input) --regions-overlap  ::  0|1|2
Include if POS in the region (0), record overlaps (1), variant overlaps (2) [1]

(bcftools-stats-input) -s --samples  ::  LIST
List of samples for sample stats, "-" to include all samples

(bcftools-stats-input) -S --samples-file  ::  FILE
File of samples to include

(bcftools-stats-input) -t --targets  ::  REGION
Similar to -r but streams rather than index-jumps

(bcftools-stats-input) -T --targets-file  ::  FILE
Similar to -R but streams rather than index-jumps

(bcftools-stats-input) --targets-overlap  ::  0|1|2
Include if POS in the region (0), record overlaps (1), variant overlaps (2) [0]

(bcftools-stats-input) -u --user-tstv  ::  TAG[:min:max:n]
Collect Ts/Tv stats for any tag using the given binning [0:1:100] A subfield can be selected as e.g. 'PV4[0]', here the first value of the PV4 tag

(bcftools-stats-input) --threads  ::  INT
Use multithreading with <int> worker threads [0]

(bcftools-stats-input) -v --verbose  ::  
Produce verbose per-site and per-sample output
