Name:  h2o


Desc:  h2o


Usage:
h2o (
      ((-c|--command <string>) | (-f|--file <file>) | 
        (-s|--subcommand <command-subcommand>) | --loadjson <file>) 
      [--skip-man] [--format {bash|zsh|fish|json|native}] [--json] 
      [--list-subcommands] [--debug] [--depth <int>] [-v|--verbose] |
      --version)


(h2o) -c --command  ::  <string>
Extract CLI options from the help texts or man pages associated with the command. Subcommand pages are also scanned automatically.

(h2o) -f --file  ::  <file>
Extract CLI options from the text file.

(h2o) -s --subcommand  ::  <command-subcommand>
Extract CLI options from the subcommand-specific help text or man page. Enter a command-subcommand pair, like git-log, as the argument.

(h2o) --loadjson  ::  <file>
Load JSON file in Command schema.

(h2o) --skip-man  ::  
Skip scanning manpage and focus on help text. Does not apply if input source is a file.

(h2o) --format  ::  {bash|zsh|fish|json|native}
Select output format of the completion script (bash|zsh|fish|json|native) (default: "native")

(h2o) --json  ::  
Output in JSON. Same as --format=json

(h2o) --list-subcommands  ::  
[Debug] List subcommands

(h2o) --debug  ::  
[Debug] Run preprocessing only

(h2o) --depth  ::  <int>
Set upper bound of the depth of subcommand level (default: 4)

(h2o) -v --verbose  ::  
Enable verbose output showing parser diagnostics

(h2o) --version  ::  
Show version

(h2o) -h --help  ::  
Show this help text
