Name:  h2o


Desc:  h2o


Usage:
h2o (
      ((-c|--command <name>) | (-f|--file <path>) | 
        (-s|--subcommand <cmd-sub>) | --loadjson <path>) [--skip-man] 
      [--format {bash|zsh|fish|json|native}] [--json] 
      [--list-subcommands] [--debug] [--depth <n>] 
      [--subprocess-budget <n>] [-v|--verbose] |
      --version)


(h2o) -c --command  ::  <name>
Parse man page, or --help output if unavailable.

(h2o) -f --file  ::  <path>
Parse options from a file containing help output.

(h2o) -s --subcommand  ::  <cmd-sub>
Parse a specific subcommand, e.g., git-log.

(h2o) --loadjson  ::  <path>
Load command data from a JSON file.

(h2o) --skip-man  ::  
Skip man page lookup, parse --help output directly.

(h2o) --format  ::  {bash|zsh|fish|json|native}
Output format for the completion script. (default: "native")

(h2o) --json  ::  
Output in JSON (same as --format=json).

(h2o) --list-subcommands  ::  
List detected subcommands (for debugging).

(h2o) --debug  ::  
Show preprocessed text without parsing (for debugging).

(h2o) --depth  ::  <n>
Maximum subcommand nesting depth to scan. (default: 4)

(h2o) --subprocess-budget  ::  <n>
Maximum help/man subprocesses during recursive subcommand scanning. (default: 1000)

(h2o) -v --verbose  ::  
Show parser diagnostics.

(h2o) --version  ::  
Show version

(h2o) -h --help  ::  
Show this help text
